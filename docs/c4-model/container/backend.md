# Backend Container
## Hakawi C4 - Container View

**Purpose:** Host all business modules through a modular NestJS monolith.

**Technology:**
- NestJS
- TypeScript
- REST API
- Passport.js for OAuth and JWT authentication
- Event-driven internal module communication

**Responsibilities:**
- Authentication and authorization via Passport strategies
- Users, stories, books, contests, notifications, messages, search, moderation, payments
- API orchestration
- Authorization and validation
- Integration with PostgreSQL, Valkey, Sanity, Paymob, email, Sentry

**Deployment:** Docker or Railway/Render
